# Политика компенсаций (только для операторов)

## Лимиты без согласования

| Ситуация | Компенсация |
|---|---|
| Курьер опоздал более чем на 2 часа | 300 бонусов |
| Курьер не приехал в слот | 300 бонусов |
| Розыск потерянного заказа | 500 бонусов |
| Двойное списание (подтверждённое) | 200 бонусов + отмена платежа |
| Просрочка возврата денег более 10 дней | 300 бонусов |

## Свыше лимита

Компенсации сверх таблицы — только через L3 (руководитель смены). Формулировка для клиента: «передам запрос руководителю, ответ в течение 24 часов».

## Чего делать нельзя

- Обещать точную дату возврата денег со стороны банка — называйте только сроки из статьи «Сроки возврата денег».
- Подтверждать производственный дефект до заключения сервисного центра.
- Оформлять компенсацию бонусами, если клиент просит деньги: денежные компенсации доступны только через L3.
