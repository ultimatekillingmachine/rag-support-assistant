# База знаний «ТехноМаркет»

Вымышленный интернет-магазин электроники и бытовой техники. Этот корпус — демо-данные для RAG-ассистента поддержки: статьи поддержки, написанные специально для проекта (не переиспользование чужой документации).

## Структура

```
knowledge_base/
├── 01_orders/         # заказы, оформление, изменение, отмена
├── 02_delivery/       # доставка, сроки, отслеживание, самовывоз
├── 03_payment/        # оплата, рассрочка, возврат средств
├── 04_returns/        # возвраты и обмен товаров
├── 05_warranty/       # гарантия, сервис, ремонт
├── 06_account/        # аккаунт, бонусы, подписка
├── 07_internal/       # внутренние регламенты операторов (audience: operator)
└── 08_stores/         # пункты выдачи, магазины
```

## Формат статьи

Каждая статья — markdown-файл с YAML-фронтматтером:

```markdown
---
slug: delivery-regions-time
title: Сроки доставки по регионам
category: delivery
audience: customer        # customer | operator
updated_at: 2026-08-15
---

Текст статьи...
```

- `slug` — уникальный идентификатор (используется в citations и eval);
- `audience` — `operator` только для внутренних регламентов (демонстрация фильтрации по правам доступа в Ф3);
- статьи писаны так, чтобы в корпусе встречались близкие по теме документы — это делает eval retrieval честным испытанием.
